# Statistical backend acceptance spike

Isolated Cargo workspace: it changes no application dependencies and needs no
Python at test time. Exact crate versions and the transitive lockfile are retained.

Run the accepted numerical cases:

```sh
cargo test --manifest-path tools/ml-spikes/statistics/Cargo.toml --locked
cargo clippy --manifest-path tools/ml-spikes/statistics/Cargo.toml --locked --all-targets -- -D warnings
```

Run the **known failing acceptance gate** for perfect separation:

```sh
cargo test --manifest-path tools/ml-spikes/statistics/Cargo.toml --locked perfect_separation -- --ignored
```

This currently fails. The normal suite explicitly reports this test as ignored;
a green normal run does **not** approve logistic regression for product release.
See [the report](../../../docs/ml-statistics-spike.md) for the observed behavior.

Regenerate the independently computed reference with Python 3.12:

```sh
python3.12 -m venv tools/ml-spikes/statistics/.venv
tools/ml-spikes/statistics/.venv/bin/pip install -r tools/ml-spikes/statistics/requirements-reference.txt
tools/ml-spikes/statistics/.venv/bin/python tools/ml-spikes/statistics/generate_reference.py
```

The fixture contains inputs, classical OLS and HC3 inference (explicit Student-t
reference), ordinary unpenalized binomial-logit inference (normal reference),
predictions, and recorded failure diagnostics. It is generated by statsmodels,
not copied from the backend under test. The multiscale OLS case deliberately
avoids the uniformly scaled designs that missed an upstream permutation bug.

Tolerance is `abs(error) <= 1e-8 + 1e-6 * abs(reference)` for these f64 cases;
this is not an import-wide or float32 compatibility promise. Aliased coefficient
values are not compared because QR and pseudoinverse choose different solutions;
identifiable predictions and rank/alias behavior are checked instead.

## Binary-logistic adapter (second batch)

`framework_statistics_spike::logistic::fit` now provides typed results/errors for
bounded unpenalized binary logit with an intercept. Nonignored tests reject the raw
backend's separation reproducer, multivariate complete/quasi separation, invalid
inputs and nonconvergence. Normal-Wald intervals match independent statsmodels
fixtures at 80%, 95% and 99% confidence.

microlp 0.6.0 proposes separation/overlap certificates; num-rational verifies them
exactly against the supplied f64 observations. Uncertifiable cases and solver limits
return errors. The spike is limited to 256 rows and 16 predictors; it is not a
production backend and does not expand FrameWork's application dependencies.

The reference generator additionally creates `separation_reference.json`: 24 seeded
integer-data cases independently classified by SciPy HiGHS. It has no dependency on
the Rust adapter. The report describes the certificate proof and retained limitations.
